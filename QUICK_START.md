# 🚀 Quick Start Guide

## How to Use Your Body Care Tracker

### 1. **Open the Application**
- Double-click `launch.html` to start
- Or open `index.html` directly in your browser

### 2. **Input Your Measurements**
Use the tabs to enter data for different body parts:

- **Face**: Measurements + skin care details
- **Hair**: Length, thickness, color, health
- **Eyes**: Measurements + health metrics  
- **Body**: Height, weight, circumferences, fitness
- **Arms**: Arm/hand measurements + nail health
- **Legs**: Leg/foot measurements + arch height
- **Back**: Width, length, posture, flexibility

### 3. **View Your 3D Mannequin**
- White mannequin updates automatically as you enter data
- Mouse: Click & drag to rotate the model
- Scroll: Zoom in/out
- Color changes based on data completion (red→green)

### 4. **Track Progress**
- Save measurements regularly
- View completion percentage
- Track changes over time
- All data stored privately on your device
