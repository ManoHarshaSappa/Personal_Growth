# Personal Body Care Tracking System

A comprehensive body care and growth tracking application with 3D visualization.

## Features

- **Data Collection**: Store detailed measurements and care data for all body parts
- **3D Visualization**: Generic white mannequin representation (shopping mall style)
- **Progress Tracking**: Monitor changes over time
- **Privacy-Focused**: All data stored locally

## Body Parts Tracked

- Face (skin condition, measurements)
- Hair (length, health, texture)
- Eyes (health, appearance)
- Hands & Arms (measurements, care)
- Legs & Feet (measurements, care)
- Back & Posture
- Overall Body (weight, measurements, health metrics)

## Technology Stack

- Frontend: HTML5, CSS3, JavaScript
- 3D Visualization: Three.js
- Data Storage: Local JSON files
- UI Framework: Custom responsive design
